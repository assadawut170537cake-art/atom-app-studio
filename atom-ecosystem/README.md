# โปรเจคอะตอม — จุดรวมโปรเจกต์หลัก

เปิด `J:\โปรเจคอะตอม\ATOM.code-workspace` ใน VS Code

## โครงสร้าง

| โฟลเดอร์ | เนื้อหา |
|---|---|
| `services/core` | เซิร์ฟเวอร์ Python เดิมจาก `J:\อะตอม` |
| `apps/flutter` | แอป Flutter เดิม เก็บโครงสร้าง build ไว้ครบ |
| `apps/kotlin` | แอป Kotlin Multiplatform เดิมจาก ATOM_MOBILE |
| `workers/pc` | PC worker เดิม รวมไฟล์ตั้งค่าส่วนตัวโดยไม่เปลี่ยนค่า |
| `integrations/hermes` | Gateway เชื่อม Hermes/Ollama |
| `config/personas-legacy` | คำอธิบายบุคลิกเดิม เก็บรักษา ไม่ได้เปิดตัวใหม่ |
| `docs` | คู่มือ แบบแปลน และข้อมูลวิจัย |
| `deployment` | การติดตั้ง Linux และสคริปต์ Windows |
| `releases/android` | ไฟล์ติดตั้ง ATOM |
| `data/legacy` | ฐานข้อมูลทดสอบเดิม |
| `archive` | ชุด SYSTEM, FRIDAY, ULTRON และไฟล์ชั่วคราวเดิม ไม่ทับกับชุดหลัก |
| `migration` | บันทึกพาธเดิม/ใหม่ SHA-256 และผลตรวจ |
| `tools` | สคริปต์จัดไฟล์และตรวจสอบ |

## ข้อสำคัญ

- การจัดครั้งนี้รวมที่เก็บไฟล์ ไม่ได้รวมโค้ดต่างรุ่นหรือเปลี่ยนระบบเป็นบุคลิกเดียวแล้ว
- ไม่ได้เปิดบริการหรือเอเจนต์ใหม่ และไม่ได้ลบ FRIDAY/ULTRON
- พาธเดิมเป็น junction หรือ hard link ไปยังข้อมูลเดียวกัน เพื่อรักษาความเข้ากันได้ ไม่ใช่สำเนา
- `J:\ATOM_MOBILE` และ `J:\อะตอม` ยังเป็นโฟลเดอร์ทางเข้าที่มีลิงก์ภายใน เพราะ Windows ล็อกโฟลเดอร์ราก
- ประวัติ Git `.git` ยังอยู่ที่ `J:\ATOM_MOBILE\.git` เพราะถูกล็อก และมี junction จาก `apps/kotlin/.git` ไปหา ต้องปิดโปรแกรมที่ล็อกก่อนย้ายส่วนนี้ให้เสร็จ
- ห้ามลบพาธเดิมด้วยคำสั่ง recursive โดยไม่ตรวจชนิดลิงก์ เพราะอาจกระทบข้อมูลจริง
- แคช Flutter บน C: และ SDK/Hermes ที่แชร์กับโปรเจกต์อื่นยังอยู่ที่เดิม ไม่ได้ย้ายหรือทำสำเนา
- พาธ Linux `/opt/atom-core` สำหรับ VPS คงเดิม ไม่ได้ย้ายบริการบนเครื่องระยะไกล
- เก็บโครงสร้างภายในแต่ละแอปไว้เพื่อไม่ให้ relative imports และ build configuration เสีย
- สคริปต์ย้ายเป็นบันทึกการดำเนินงานครั้งเดียว ไม่ควรรันซ้ำหลังจัดประเภทไฟล์แล้ว

## ตรวจสอบ

```powershell
python 'J:\โปรเจคอะตอม\tools\verify_project.py'
git -C 'J:\โปรเจคอะตอม\apps\kotlin' status --short
```

การทดสอบ API ใช้ฐานข้อมูลชั่วคราวและ secret ทดสอบ ไม่เรียกเซิร์ฟเวอร์จริงหรือ Google Drive
ยังไม่ได้ยืนยันการ build Android/iOS/Windows ทั้งชุด หรือการทำงานของบริการระยะไกล
